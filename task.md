Test task — LinkedIn engagement automation

We're prototyping a small Python automation: it reads your LinkedIn feed, picks posts worth engaging with, and helps draft a reaction or comment that reads like you wrote it (not AI-fluff).

Build a Python + Playwright script. Use any AI assistant you actually use.

One task — three depths

You decide how far to go.

Quality matters more than depth reached. Level 1 done thoughtfully beats all three done sloppily. Stop when you've reached your own quality bar.
Level 1 — Read and react. Sign into LinkedIn, read your home feed, "like" the top 10 interesting posts. Print author + first 200 chars + outcome to stdout.

Level 2 — Comment thoughtfully. Pick the 2–3 most interesting posts from those 10 (your rule, defend it briefly). Use an AI assistant to draft a comment that reads like a human wrote it. Don't post it — print it next to the post.

Level 3 — Profile-aware. Before commenting, visit each post's author profile, gather what context you can (headline, recent activity, mutual ground, experience, etc), and use that to make the comment substantively better. Briefly note what tripped you up.

Time & submit

30 min minimum, 2 hours maximum. Submit anywhere within that window.

Deliverable: GitHub repo + README:

Which level you reached, and how long it actually took
How to run it (the exact commands a teammate would type)
A sample_output.txt captured from one real run
Anything a teammate would need to understand your choices — keep it short, write what you think matters
